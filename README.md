# CraveCart - Food ordering and delivery system

# Project overview
CraveCart is a food ordering and delivery application that demonstrates 6 software design patterns in a real world scenario.
Users can browse restaurants, order food, customize meals, make payments, and track deliveries in real time.

How to use the application

1. Browse Restaurants
* Restaurants are organized into 3 categories: Fast food, premium and healthy
* Click any restaurant card to view its menu

2. Select and customize a meal
* Click on a menu item to see customization options
* Available extras depend on the food type

3. Add to cart
* Select your desired extras and click "Add to Cart"
* The cart count updates in the top-right corner
* You can add food from different restaurants to the cart

4. View cart
* Click the cart button to open the cart sidebar
* View tems, remove individual items, or clear the whole cart

5. Apply discounts
* Promo code: enter one of these 'CRAVE20'(20% off), 'CRAVE10'(10% off), 'FREEDELIVERY'(R25 off)
* Loyalty points: enter points(10 points = R1 discount). You have 500 points at the start

6. Select Payment method
* You can choose to use a Credit card, EFT/Bank Transfer or Payfast

7. Place order
* Click PLACE ORDER
* Watch real time order tracking notifications
* Order confirmation shows earned loyalty ponts
